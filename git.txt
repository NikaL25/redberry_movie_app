COMMIT 12
refactor(dependencies) - align module boundaries

Изменено:
- pages → features / components / utils

ARCHITECTURAL APPROACH
======================

Текущая архитектура до аудита:
Смешанная feature-based + layer-based структура (pages / features / app / api / components). Не FSD.

Выбранная архитектура:
Та же смешанная модель, с уточнённым размещением feature-hooks и удалением мёртвых файлов.

Почему:
Приложение среднего размера: 4 страницы, 5 доменов, Redux только для auth/booking, данные с API через React Query. Feature-модули уже совпадают с продуктовыми сценариями. Переход на FSD или дробление больших экранов не дал бы ясности и рискнул бы поведением.


IMPORTANT
=========

Логика приложения не изменялась.
Поведение приложения должно оставаться идентичным исходному состоянию.
